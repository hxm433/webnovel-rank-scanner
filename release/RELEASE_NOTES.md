## 网文扫榜工具 v1.0.1

**本版修复：起点只能扫到 20 条的问题。**

### 修了什么

起点走 www 站多页能抓 **500 条**，但需要浏览器内核**并且它能正常无头运行**。
之前的版本在这条路失败时会降级到移动站（每榜 20 条），而且报告里写的失败原因
**是错的** —— 明明找到了浏览器，却说"未检测到可用浏览器内核"，让人以为是没装浏览器。

现在：

- **报告如实写原因**：区分"没找到浏览器内核"与"浏览器产出空 DOM（exit=0）"；
- **空 DOM 自动重试一次**（换全新 profile）—— 这种情况常常是瞬时的；
- **错误里带上排查方向**："浏览器把请求交给了另一个已在运行的实例，
  若那个实例是以管理员身份运行的，请改用普通权限重启它"；
- 新增自检命令，可以自己确认渲染通道：

  ```
  网文扫榜工具.exe --selftest-render=r.txt out
  ```

  看 `r.txt`：会打印浏览器路径、WebView2 版本、真实渲染耗时、解析到的行数。

### 下载

下载下面的 `webnovel-rank-scanner-v1.0.1.zip` → 解压 → 双击 `网文扫榜工具.exe`。

## 网文扫榜工具 v1.0

**Windows x64 · 单文件 exe · 解压即用 · 不需要装任何运行环境**

覆盖 **起点 / 番茄 / 七猫 / 晋江** 四个平台的榜单采集与分析。
纯 Dart 手写，只依赖 `package:ffi` 一个包 —— 界面是 Win32 自绘的，
连 PNG 编解码、GBK 解码、deflate 压缩都是手写的。

### 下载与运行

下载下面的 `webnovel-rank-scanner-v1.0.zip` → 解压到任意可写目录 → 双击 `网文扫榜工具.exe`。

> ⚠️ 别放在 `C:\Program Files\` 这类需要管理员权限的目录里 —— 数据要写在 exe 同级的 `out/`。

### 第一次用

1. 点右上角「**扫榜设置**」→ 勾几个榜 → 点「开始扫榜」（约 35 秒）；
2. 左侧点榜单看明细，点书名看详情；
3. 抓了多天之后，切到「**历史对比**」看趋势与解读。

### 包内文件

| 文件 | 说明 |
|---|---|
| `网文扫榜工具.exe` | 主程序（约 8.6 MB） |
| `启动.cmd` | 双击启动（顺带打印数据目录位置） |
| `使用说明.md` | 逐步操作指南 |

### 这个版本有什么

- **四个平台采集**：起点 www 站多页（最多 500 本，含字体反爬破解）、
  番茄、七猫、晋江（gb18030）；robots 检查 + 全局限速 + 域名白名单；
- **跨期趋势**：同一张榜多份快照对比，结论分「事实 / 候选原因」两档，可复算；
- **导出**：Excel（三张表）/ CSV / JSON / 榜单长图 / 趋势图 / 附件，
  落点可固定也可"每次先问文件夹"；
- **单文件网页**：数据全内嵌，双击就开，不联网、不需要服务器；
- **零第三方依赖**：单 exe，不写注册表、不联网上报。
