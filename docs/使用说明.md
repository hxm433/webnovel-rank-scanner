## 1. 安装与启动

**不需要装任何运行环境。**

1. 从 [**Releases 页面**](https://github.com/hxm433/webnovel-rank-scanner/releases/latest)
   下载 `webnovel-rank-scanner-v1.0.zip`（[直链](https://github.com/hxm433/webnovel-rank-scanner/releases/download/v1.0/webnovel-rank-scanner-v1.0.zip)）；
2. 解压到**任意可写目录**（不要放在 `C:\Program Files\` 这类需要管理员权限的地方）；
3. 双击 `网文扫榜工具.exe`。

界面是深色的，右上角有四个按钮：**扫榜设置 / 重载数据 / 数据管理 / 导出**，
最右边是主题切换与版本号。

> 想换主题：点右上角的「深色 / 浅色」按钮，设置会记住。

---

## 2. 第一次扫榜

点右上角「**扫榜设置**」，会打开一个独立窗口：

1. 左边是一棵树：**平台 → 榜单**。点平台名可以整块勾选；
2. 每个榜右边可以单独改「**本数**」（默认 20，起点最多 500）；
3. 底部会显示「已选 N 个榜、合计 M 本」；
4. 点「**开始扫榜**」。

第一次大约 **35 秒**（16 次请求，每次间隔 1.5 秒 —— 这是对站点的礼貌，不要调太小）。

扫完窗口会自动关掉，左侧栏出现刚抓的榜单。

> **看到「【降级】移动站单榜 20 条」？**
> 起点要装了 Edge / WebView2 才能走 www 站多页（最多 500 本）。
> 没有浏览器内核时会降级到移动站，每榜只有 20 条 —— 界面会明确标出来，不会骗你。

---

## 3. 看榜单明细

左侧点一个榜单，右边就是「**榜单明细**」页：

- **每一行**：名次、封面、书名、作者、题材、指标、备注；
- **点书名**：弹出这本书的详情（指标明细、其他字段、各期名次变化）；
- **点「打开」**：把详情页地址交给系统默认浏览器（地址同时会复制到剪贴板）；
- **点封面**：放大看；
- 表格可以**横向滚动**（列多），也可以**竖向滚动**。

顶部三个标签页：**榜单明细 / 历史对比 / 跨榜分析**。

---

## 4. 历史对比（跨期趋势）

同一个榜抓了**多天**之后，切到「**历史对比**」标签：

1. 先选一个「**对比基准**」（拿哪一期做参照）；
2. 折线图显示各期变化；下面列出「上升最快 / 下降最快 / 新上榜 / 掉榜」；
3. 最下面是**解读块**：结论分两档 ——
   - **事实**：直接从数字算出来的（"这 3 本连续 4 期在榜"）；
   - **候选原因**：推测（"可能与更新频率有关"）—— 会明确标注"不是定论"。

> 只有**同一张榜**、**同一个题材**的多期快照才能对比。跨题材比大小没有意义，
> 界面上也做了提示。

---

## 5. 跨榜分析

切到「**跨榜分析**」标签：看**同一本书**在不同榜 / 不同平台的表现，
以及哪些书同时出现在多个榜上。

> ⚠️ 各平台的指标口径不同（起点是月票、番茄是热度、七猫是热度+字数），
> **不要跨平台比数值大小** —— 界面里也写了这句。

---

## 6. 导出

点右上角「**导出**」，菜单分三组：

**第一组：榜单（这一份快照）**
| 菜单项 | 产物 |
|---|---|
| Excel 表格（.xlsx，多张表） | 三张表：榜单明细 / 指标口径 / 榜单信息 |
| CSV 明细表 | 带 BOM，公式注入已消毒 |
| JSON（单份快照 + 分析） | 结构化数据 |
| 榜单图片（PNG 长图） | 带封面，适合直接发给别人 |
| 附件（图片 / 文本） | 单独导出快照里带的附件 |

**第二组：趋势分析 / 历史对比**
| 菜单项 | 产物 |
|---|---|
| 趋势图（PNG，含解读） | 折线 + 解读块 |
| 全部快照汇总（含两两对比） | 一份跨期汇总表 |

**第三组：导出到（落点）**
| 菜单项 | 作用 |
|---|---|
| 设置导出位置… | 设一个固定落点，**记住**（默认 `out\导出`） |
| 每次导出前先问文件夹（当前：开/关） | 打开后每次导出都先弹文件夹框 |

> 默认是「**一键出文件**」：点菜单 → 直接落盘 → 弹一个完成提示（含文件名与目录）。
> 想每次都自己挑地方，就把第三组那个开关打开。
> **取消选文件夹 = 本次不导出**，绝不会悄悄存到别的地方。

## 7. 生成单文件网页

命令行（在源码目录下）：

```bash
dart run bin/page.dart --open
```

会生成 `榜单页.html`：**数据全内嵌**，双击就开，不联网、不需要服务器。
可以发给别人，也可以当离线归档。

网页上还能：
- **点书名看详情**（弹面板，不发任何请求）；
- **导出当前榜 CSV**（口径与桌面端一致）。

---

## 8. 数据管理

点右上角「**数据管理**」：

- 看所有快照（按平台 / 时间）；
- **删除**单份快照（删之前会确认，破坏性操作默认选中「否」）；
- 「**应用保留策略**」：按你在设置里填的"每个系列保留 N 份"清理旧快照
  （**默认是不限**，不填就什么都不删）；
- 「重建索引」：本地索引 `out/扫榜/index.json` 坏了或丢了时重建；
- 「打开数据目录」。

---

## 9. 命令行

不想开界面也能用（需要 Dart SDK）：

```bash
# 有哪些榜（本地枚举，不联网）
dart run bin/scan.dart boards

# 抓一轮
dart run bin/scan.dart sweep --limit 20 --ms 1500

# 抓指定的榜
dart run bin/scan.dart fetch --source qidian --board 月票榜 --limit 50

# 生成网页
dart run bin/page.dart --open
```

## 10. 常见问题

### 点「打开」跳不到浏览器？

工具把地址交给**系统默认浏览器**。三种情况会让你觉得"没反应"：

1. **浏览器开着多个窗口** —— 新页面可能开在**另一个窗口/后台标签**里。
   **先看看任务栏有没有浏览器图标在闪**，或按 `Alt+Tab` 找一下。
2. **浏览器以管理员身份运行** —— Windows 的完整性级别隔离（UIPI）不允许
   普通程序把网址交给管理员程序。浏览器会弹
   「现有实例正在以提升的权限运行，是否要用普通权限重启现有实例？」
   → 在那个框里点「**是**」；或者**右键本工具 → 以管理员身份运行**（两边同级就不拦）。
3. **地址每次都会自动复制到剪贴板** —— 直接粘贴到地址栏即可。

### 起点只有 20 条？

起点走 www 站多页能抓 **500 条**，但需要浏览器内核**并且它能正常无头运行**。
降级到移动站（每榜 20 条）时界面会标「【降级】」，报告里会写**具体原因**：

| 报告里的原因 | 怎么办 |
|---|---|
| 没找到浏览器内核 | 装 Edge 或 WebView2 Runtime |
| **浏览器产出空 DOM（exit=0）** | 浏览器把请求**交接给了另一个已在运行的实例**。最常见的原因是那个实例**以管理员身份运行**（UIPI 挡住交接）→ 用普通权限重启浏览器，或把浏览器完全退出后再扫 |

自检渲染通道（在程序目录下）：

```bash
网文扫榜工具.exe --selftest-render=r.txt out
```

看 `r.txt`：会打印浏览器路径、WebView2 版本、真实渲染耗时与解析到的行数
（第 1 页应为 20 行）。

### 抓不到数据？

站点改版会导致解析失败 —— 界面和 `out/reports/` 里的报告会写明原因。

### 书名显示成乱码 / 「名待补」？

番茄和起点有**字体反爬**。工具会就地破解；破解不了的部分会标成
「名待补」而**不会给你一个错的名字**。

### 数据能换电脑吗？

能。把整个 `out/` 目录拷过去即可（见下一节）。

## 11. 数据目录长什么样

全部在 **exe 同级**的 `out/` 下：

```
out/
├─ 扫榜/
│  ├─ qidian/            每个平台一个目录
│  │  └─ 月票榜_20261003.json      一份快照 = 一个文件
│  ├─ index.json         本地索引（坏了可以重建）
│  ├─ _open_log.txt      「打开链接」的现场记录（排查用）
│  └─ _startup.txt       启动记录（排查用）
├─ 导出/                 默认导出落点
└─ reports/              每轮扫榜的质量报告（md）
```

- **不写注册表**（界面偏好存在 `out/扫榜/ui.json`）；
- **不联网上报**任何东西；
- 想迁移/备份，整个 `out/` 拷走就行。

---

## 12. 卸载

1. 关掉程序；
2. 删掉整个目录。

没有安装过程，也没有残留（注册表、AppData 都不写）。
